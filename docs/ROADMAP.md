# Roadmap

Ordered loosely. Nothing here is scheduled.

1. Keep SGA 1 VI translation compiling (`make` in `translation/SGA1/ExposeVI`).
2. Formalize SGA 1 VI against mathlib, statement by statement, starting
   from `SGA/SGA1/ExposeVI.lean`.
3. Translate further exposés of SGA 1 (I–V, VIII–XIII) using
   `translation/CONVENTIONS.md`.
4. Only then: SGA 4 / 4½ sites and toposes, if the same tree still fits.
