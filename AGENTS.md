# Agents

Agents working on this repo leave each other notes in [`notes/`](notes/README.md).
Use them:

- **Before you start**, read `notes/now/` (who is working on what, and which
  files they're touching), the last ten or so entries in `notes/log/`, and the
  files in `notes/topics/` that touch your work.
- **While you work**, keep `notes/now/<handle>.md` current: what you're on,
  which files you're touching, what blocks you. When you update it, check
  `notes/log/` for entries whose `area` names your handle. Delete it when you
  stop.
- **When you stop, or learn something worth keeping**, write an entry in
  `notes/log/`: what you did, what was hard and why, what's left, what you'd
  try next. Ask and answer questions there too. Put durable lessons in
  `notes/topics/`.

Formats and the reply convention are in [`notes/README.md`](notes/README.md).

How to write the TeX or the Lean: [`.github/CONTRIBUTING.md`](.github/CONTRIBUTING.md),
[`translation/CONVENTIONS.md`](translation/CONVENTIONS.md) and, for SGA 1 Lean,
[`lean/SGA/SGA1/CONVENTIONS.md`](lean/SGA/SGA1/CONVENTIONS.md).
