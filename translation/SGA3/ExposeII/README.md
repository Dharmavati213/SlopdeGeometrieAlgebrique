## Typographical corrections

Corrected in the English and marked `% typo:` in the source: a doubled
closing parenthesis *(Ceci … a)).* → *(Ceci … a).* (after 4.2); *les
proposition* → *les propositions* (4.3); *On un isomorphisme* → *On a un
isomorphisme* (4.3.1); unbalanced Hom_S(I_S(ℳ, F) →
Hom_S(I_S(ℳ), F) (4.3.4).
