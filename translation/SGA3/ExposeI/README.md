## Typographical corrections

Corrected in the English and marked `% typo:` in the source: *les produit
fibrés* → *les produits fibrés* (1.7); *pour pour* → *pour* (2.2, remark);
*les application canoniques* → *les applications canoniques* (4.6.2);
*sur les définition* → *sur les définitions* (proof of 4.6.2); *cocyle* →
*cocycle* (6.8.4).
