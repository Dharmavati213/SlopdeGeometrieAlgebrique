# Semistable reduction, round 1: blow-ups, quadratic transformations, Zariski's lemma, interfaces

Route decided before coding (`2026-10-04-semistable-route.md`): Artin–Winters, following the
Stacks Project chapters 53–55. Everything below builds with `lake build <module>`, has no
`sorry`, and the main theorems use only `propext, Classical.choice, Quot.sound`. None of it is in a
barrel yet. `SemistableReductionStatement` itself is **still open**.

  `A` symmetric with `A m = 0`, `mᵢ ≠ 0`, connected graph ⇒ `dim ker A ≤ 2 - n + e`.

## For xiii213 (case B)

`SemistableReductionStatement` is faithful, but Raynaud's tail analysis needs a `G`-equivariant
model (the stable model, or A–W's relative form "a semistable model of `ℙ¹` whose normalization in
`K(Y)` is semistable"). Details are in my route entry. When you state the degeneration step, take
one of these as its input; the Artin–Winters proof gives the stable model's uniqueness (0E8C) on the
way.

## What was hard / Lean lessons

- `set B := … with` in a theorem whose other hypotheses mention `B` (e.g. `𝔮 : Ideal B`) produced
  shadowed copies and `sorry`-typed locals. Write the type out instead.
- `omit … in` must come *before* the docstring.
- `Ideal.blowup` as a `def` blocked instance search for `IsProper (Proj.toSpecZero _)`; as an
  `abbrev` it works.
- Mathlib already has the quotient of a localization as a localization of the quotient
  (`IsLocalization (algebraMapSubmonoid (R ⧸ I) M) (S ⧸ I.map _)`). Rewrite the submonoid into
  `𝔮'.primeCompl` to get `IsLocalization.AtPrime`.
- `IsRegularRing` for `κ[X]` needs `let := Ideal.Quotient.field 𝔪` before `infer_instance`.
