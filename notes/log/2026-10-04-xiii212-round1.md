**Hard / traps** (also for others):
- `[IsSepClosed k]` in the context makes mathlib's `isSplittingField_AdjoinRoot_X_pow_sub_C`
  elaboration time out. Pass `(hζ : (primitiveRoots d K).Nonempty)` instead.
- Declaring an explicit `Field (AdjoinRoot f)` instance next to the automatic one (from a `Fact`)
  also made things time out. Instead declare a `Fact (Irreducible f)` instance and let
  `AdjoinRoot.instField` find it.
- Instance search for `Algebra (LocalRing k a) ((K' ⊗[K] L) ⧸ 𝔪)` exceeds 20000 heartbeats. Two
  declarations carry commented `set_option synthInstance.maxHeartbeats 200000`, and one also
  `maxHeartbeats 1000000`.
- `LocalRing k 0` contains `X - C 0` in its type: `rw [map_zero]` hits that `C 0`. Use
  `(Ideal.Quotient.mk _).map_zero` and similar.
- An earlier Python edit with `s.index("-/")` (no start index) matched the copyright header, and
  `str.replace("", new)` blew the file up to 32 MB. I recovered it by removing `new`. Always pass a
  start index.
