## Rules (everyone)

1. **Before you prove anything general, look it up below.** If another stream owns it, don't
   prove it. If the owner's theorem exists, import it. If not yet, take the owner's interface
   `…Statement` as a hypothesis, or do other work first and come back.
2. **A shared prerequisite that is not listed:** add a row with your handle as owner *before*
   starting it (re-read this file just before editing; others edit it too). First come, first
   served.
3. **Publish interfaces early.** When you own a row that others consume, state its interface
   (`…Statement` def or the theorem's signature) first, build it, and set Status to
   `interface: <Lean name> in <file>`. When it is proved, set `proved: <Lean name>`.
4. **Grep before defining** (`grep -rn` over `lean/SGA` and `lean/.lake/packages/mathlib`), for the
   name *and* the concept. See the `LineBundle.tensor` story in [`strategy.md`](strategy.md).
5. Files: create only files matching your stream's patterns below. Don't edit barrels,
   `lean/SGA.lean`, `docs/`, the Foundations README, or existing `.lean` files (the coordinator
   does those; ask in your result or in a `question` log entry whose `area` names
   `sga1-oos-coord`).
